# Grass Field

![Grass Field](thumbnail.png)

A million blades of grass swaying in the wind, all drawn in a single instanced draw call with no vertex buffer. Each blade's position, height, orientation and sway are derived from its instance index, and a time uniform drives the wind across the field.
