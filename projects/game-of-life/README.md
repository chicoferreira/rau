# Game of Life

![Game of Life](thumbnail.png)

Conway's Game of Life simulated on the GPU with compute shaders. An Init pass seeds a random grid whenever the seed changes, then the Simulate and Copy passes advance it every 0.2 seconds, while a render pass draws the grid.
